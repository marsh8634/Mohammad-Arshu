# Personal Portfolio Website

A modern and responsive portfolio website built to showcase my skills, projects, education, certifications, and contact information. This portfolio reflects my journey as a Frontend and Full Stack Developer and highlights the technologies I work with.

## Features

* Fully responsive design for mobile, tablet, and desktop devices
* Modern glassmorphism-inspired UI
* Smooth scrolling navigation
* Interactive typing animation
* Animated particles and mouse glow effects
* Project showcase section with live demo and source code links
* Skills and technology stack display
* Education and certification section
* Contact form integrated with WhatsApp
* Social media integration
* Smooth reveal animations while scrolling
